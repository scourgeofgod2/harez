# Açık Linear frontend

## Karar
Tüm görünür arayüz Linear'ın açık ürün diline geçer: nötr gri zemin, beyaz yüzey, 1px hairline, 6px radius, 13px yoğun tipografi, indigo vurgu `#5E6AD2`. Sohbet, auth ve admin işlevleri, API'ler ve veri modeli değişmez. Koyu tema toggle ile kalır. Yeni paket yok — mevcut shadcn/base-ui + Tailwind v4 tokenları kullanılır.

## Tokenlar — `app/globals.css`
`:root` (açık, varsayılan):
- canvas `#F7F8F8`, surface/card/popover `#FFFFFF`, sidebar `#F7F8F8`
- text `#1B1F23`, muted `#6B6F76`, faint `#9A9DA3`
- border/input `#E6E6E6`, hover `#D0D3D6`
- primary/ring `#5E6AD2`, primary-foreground `#FFFFFF`, soft wash `#EEF0FF`
- destructive `#E5484D`, danger wash `#FEF2F2`
- `--radius: 6px`; `--radius-lg` kartlar için 8px

`.dark` aynı vurguyu koyu Linear yüzeyine taşır: canvas `#0F1011`, surface `#191A1B`, border `#2A2B2D`, text `#F7F8F8`, muted `#8A8F98`.

Base: body 13px / 1.5, letter-spacing `-0.011em`. Scrollbar thumb border-hover. Gölge neredeyse yok (`shadow-xs` sadece popover/dropdown).

## Bileşenler
- `components/ui/button.tsx`: default indigo, hover `#4F5BC4`; outline/ghost hairline + muted hover; height 28px, radius 6px, 13px/500. Aktif `translate-y` kaldırılır.
- `components/ui/input.tsx` + `textarea.tsx`: beyaz zemin, 6px, focus `0 0 0 3px` soft indigo. Hata destructive + danger wash.
- `components/theme-toggle.tsx`: emoji yerine `Sun`/`Moon` (zaten çalışan lucide exportları), 28px kare outline.

## Ekranlar
- **Sohbet** `app/assistant.tsx` + `thread.aui.tsx`: header 48px, hairline, blur yok. Composer tek satır pill değil — 6px bordered kutu, gönder indigo kare ikon. Kullanıcı balonu `#EEF0FF` / indigo metin değil, açık gri kutu + koyu metin. Asistan düz metin. Welcome: küçük "harez.io" eyebrow + 22px "Bugün sana nasıl yardımcı olabilirim?". Öneri listesi kart grid değil, hairline satırlar.
- **Sidebar** `threadlist-sidebar.aui.tsx`: sahte nav (Görevlerim, Toplantılarım, yükseltme kartı) kalkar. Kalan: marka satırı, Yeni sohbet, arama, Bugün/Dün/Daha önce, altta kullanıcı + ayarlar (admin) + çıkış + tema. Aktif sohbet `bg-muted`, 6px.
- **Thread list** `thread-list.aui.tsx` + follow-up: 13px, uppercase 11px grup etiketleri, menü 6px radius. Follow-up chip'ler pill değil, küçük outline.
- **Giriş / kayıt**: ortada 360px beyaz kart, 8px radius, eyebrow, indigo submit. Arka plan canvas.
- **Admin**: aynı kart dili — header strip yok, section başlığı 13px/600 + hairline. Tablo 12px, header muted, satır hover. Badge'ler soft indigo / muted. Tema toggle header'da kalır.

## Doğrulama
`npm run dev` ile `/`, `/giris`, `/kayit`, `/admin`:
- Varsayılan açık; toggle koyuya geçip yenilemede kalıyor.
- Primary her yerde indigo, radius 6px, kartlar düz (büyük gölge/pill yok).
- Sohbet gönder / geçmiş / model seçici / admin CRUD davranışı bozulmamış.
- `tsc` yalnızca önceden var olan `ai` / `submission` / lucide hatalarını vermeli; yeni dosyalarda yeni hata olmamalı.
